🚀 How to Use

Step 1: Add the Script

Add this line before the closing </body> tag in your HTML files:

<script src="dist/react-enhancements.js"></script>

Step 2: Test the Features

Scroll down this page to see all the features in action:

  • Look at the bottom-right for the Floating Booking Button
  • Check the top-right for the Weather Widget
  • Notice the Scroll Progress Bar at the very top
  • Watch cards fade in as you scroll

Step 3: Customize

Edit dist/react-enhancements.js to change:

  • Phone numbers and WhatsApp links
  • Email addresses
  • Weather location
  • Colors and styles
